# TermSpread by TaxPros Financial — demo

The planning workspace for TaxPros Financial agents, as an interactive demo: client facts, findings on the 2026 tax law,
the what-if tax plan, a term-plus-invest plan and the client presentation.

- Open the demo: https://eddyperez2m-commits.github.io/termspread-demo/
- Desktop app, which updates itself from this page:
  [Mac](https://github.com/eddyperez2m-commits/termspread-demo/releases/latest/download/TermSpread-Mac.zip) ·
  [Windows](https://github.com/eddyperez2m-commits/termspread-demo/releases/latest/download/TermSpread-Windows.zip) ·
  [install steps](https://github.com/eddyperez2m-commits/termspread-demo/releases/latest/download/Install-TermSpread.txt)
- The clients are fictional. Nothing you type is saved or sent anywhere; reloading starts over.
- Figures are educational estimates, not tax or legal advice.
